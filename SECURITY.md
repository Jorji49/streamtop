# Security policy

## Supported versions

Security fixes are provided for the latest release.

## Reporting

Do not open a public issue for an undisclosed vulnerability. Report it through
[GitHub private vulnerability reporting](https://github.com/Jorji49/streamtop/security/advisories/new).

Include the affected version, reproduction steps, expected impact, and any
suggested mitigation. Secrets and signed stream URLs must be redacted.

You should receive an acknowledgement within 72 hours. A fix and disclosure
timeline will be coordinated after the report is reproduced.
